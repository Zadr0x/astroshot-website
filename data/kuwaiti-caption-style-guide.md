## 2) MASTER PATTERNS — Universal Kuwaiti copywriting rules

1) سؤال البداية (Hook Question)
- Rule: ابدأ بسؤال بسيط أو ثنائي يفتح السالفة ويستدعي تعليق.
- Example: "إنتوا مع فريق الماي والتمر ولا دايركت على العيش واللحم؟"

2) خل + حل سريع
- Rule: استخدم "خل" لتقديم حل مريح يلغي عناء القارئ.
- Example: "خل السحور علينا واطلب الحين."

3) وقت الخدمة كميزة
- Rule: اذكر ساعات التوافر وخاصة المتأخرة كعامل إقناع.
- Example: "نوصلكم يوميًا للساعة ٣:٣٠ الفجر."

4) لمّة/قعدة كزاوية بيع
- Rule: أربط المنتج باليمعة/الديوانية/الغبقة لتعظيم القيمة الاجتماعية.
- Example: "بوكس واحد يكفي يمعتكم ويخلّي الجو أحلى."

5) دمج عربي + إنجليزي بخفّة
- Rule: أضف كلمة/سطر إنجليزي قصير للمزاج أو التقنية، بدون إفراط.
- Example: "Say cheese… White Mango is back!"

6) حميمية محليّة/قرابة مجتمعية
- Rule: نادي الجمهور بألفاظ أهل/حبايب/أهل المنطقة.
- Example: "حبايبنا واهلنا بالجهراء… حياكم الله."

7) موسمية/مناسبة
- Rule: وصّل العرض بلحظة المجتمع (رمضان/العيد/ڤالنتاين/ويكند).
- Example: "ريوق العيد ما يكمل بدون…"

8) توجيه منصّات واضح
- Rule: اختم دائماً بمسار فعل محدد (لينك، تطبيقات التوصيل، تلفون).
- Example: "الطلب عبر موقعنا أو كل تطبيقات التوصيل."

9) قيمة مُجمّعة + سعر مباشر
- Rule: في عروض التجزئة، اذكر محتوى البوكس والسعر بوضوح.
- Example: "٦ سندويش، ٣ بطاط وصوص… كل هذا بس 10.500 د.ك."

10) إيموجي وظيفية
- Rule: استخدم إيموجي داعمة للمعنى (⏰ للتوقيت، 📲 للطلب)، لا تزاحم النص.
- Example: "حدّث التطبيق الحين 📲"

11) اسم المكان كفخر/دليل
- Rule: حدد الموقع بدقة واعمل shoutout لأسماء تجارية معروفة.
- Example: "فرعنا بالأفنيوز، عند مدخل أديداس وستاربكس."

12) علامات تعجب/استفهام مدروسة
- Rule: كثّف الإحساس بالحماس بدون إفراط (واحدة إلى اثنتين كافية).
- Example: "تعرفونها؟"

13) تعليم سريع + CTA
- Rule: قدّم فائدة/نصيحة مختصرة ثم ادعُ للفعل.
- Example: "وجبة الكومبو متعة… ونصيحة اطلب إكسترا صوص."

14) ثبات نبرة الهوية
- Rule: احفظ صوت العلامة (دافئ/مهني/مغامر) عبر كل المنشورات.

15) إفصاح/تنظيم عند الحاجة
- Rule: للمحتوى المالي/المنظم، أرفق إفصاحاً ثابتاً بنسق ثابت.


## 3) KUWAITI POWER VOCABULARY

- Openers
  - شنو السالفة؟ — What’s up/what’s the story?
  - هااا؟ — So? / Hey?
  - منو معانا؟ — Who’s in?
  - جاهزين؟ — Ready?
  - تتخيلون؟ — Can you imagine?
  - جم مرة صارت وياكم؟ — How many times did this happen to you?

- Endearments
  - حبايبنا — Our loved ones
  - أهلنا — Our people/family
  - يا جماعة — Folks
  - ربعنا — Our buddies
  - الغالين — Dear ones
  - بنات الديرة/عيال الديرة — People of our town

- CTAs
  - اطلب الحين — Order now
  - حدّث التطبيق — Update the app
  - حياكم — You’re welcome/come by
  - احجز مكانك — Reserve your spot
  - دزّلنا مسج/خاص — Send us a message/DM
  - تواصلوا ويانا — Contact us
  - اللينك بالبايو — Link in bio
  - اختَر على ذوقك — Choose your way
  - سجّل الحين — Register now
  - شغّل الإشعارات — Turn on notifications

- Time markers
  - الحين — Now
  - باجر — Tomorrow
  - من الساعة … لي … — From … to …
  - قبل الأذان/بعد الفطور — Before adhan/after iftar
  - هالويكند — This weekend
  - من بدري — Early
  - لين ٣:٣٠ الفجر — Until 3:30 AM

- Intensifiers

  - غير — Different/special
  - أقوى — Strongest

  - بطاط — Fries
  - دياي — Chicken
  - عيش — Rice

## 4) FORMULAS FOR ASTROSHOT (Premium VFX/3D)

Formula 1: سؤال + قبل/بعد + حل "خل" + CTA
- Structure: سؤال يلمس ألم بصناعة المحتوى + مشهد قبل/بعد VFX + "خل" كحل + مسار فعل.
- Example (موضوع: Product CGI):
  - "منتجك يطلع عادي بالتصوير؟ قبل: لقطة ستاندرد… بعد: CGI يلمع ويبيع بروحه. خل التحويل علينا، وخلّك على الاستراتيجية. اطلب الديمو الحين من موقعنا 📲"

Formula 2: قيمة مركّبة + توقيت تسليم + ثقة/حرفنة
- Structure: 3 مزايا VFX + إطار زمني واضح + تأكيد دقة/حرفية + CTA.
- Example (موضوع: Set Extension/Matchmove):
  - "سينماتك تكبر بدون لوكيشنات: Set Extension دقيق + Matchmove نظيف + Grade سينمائي. تسليم أول نسخة خلال ٧٢ ساعة عمل. تواصلوا ويانا وخنوّن المشهد يصير عالم."

Formula 3: قصة مصغّرة + هوية محلية + Tech flex قصيرة
- Structure: قصة نجاح سريعة مع عميل محلي + جملة فخر + ذكر أدوات تقنية مختصر + دعوة.
- Example (موضوع: 3D Crowd/Unreal):
  - "مع فريق محلي، ملعب صار فلّ بالجمهور خلال يومين—بدون كومبارس. فخورين بشغل الديرة، باستخدام Unreal + 3D Crowd Sim. تبي نفس الروح بمشروعك؟ حياك على الخاص."

Bonus micro-hooks Astroshot:
- "تبي لقطة تقول واو من أول ثانية؟"
- "CGI نظيف ولا فوضى بوست؟ اختر الذيب."
- "مشهدك… بس أقوى، أسرع، أذكى."

نبرة Astroshot: كويتي مهذب/فاهم تقنياً، بريميوم، ثقة بدون صراخ سعري، استعمال إنجليزي تقني مختصر مدروس (CGI/Unreal/Tracking/Grade).


## 5) DO / DON'T TABLE

| DO (افعل) | DON'T (لا تفعل) |
|---|---|
| ابدأ بسؤال هوك بسيط "شنو/منو/ها؟" | لا تفرّع بأسئلة طويلة تربك القارئ |
| استخدم "خل" لتقديم حل سريع ومريح | لا تستخدم أوامر فجة أو نبرة استعجال مبالغ فيها |
| حدّد ساعات التوافر بدقة وبالأرقام العربية | لا تترك التوقيت مبهم أو وعود غير دقيقة |
| اربط الرسالة بيمعة/ديوانية/غ🚫بقة/موسم | لا تتجاهل المناسبات المحلية الكبرى (رمضان/العيد) |
| اختم بمسار فعل واضح (لينك/تطبيق/اتصال) | لا تنهِ بدون CTA واضح |
| امزج إنجليزي تقني/مزاجي بخفّة | لا تكثر كلمات إنجليزية لدرجة تشوّش الهوية |
| استخدم إيموجي وظيفية محدودة | لا تحشو سطورك بإيموجي كثيرة |
| حيّ الجمهور بألفاظ أهل/حبايب/ربيع | لا تستخدم لهجات غير كويتية أو ألفاظ دخيلة بكثرة |
| حافظ على صوت بريميوم واثق لعلامتك | لا تدخل في منافسة سعرية مباشرة إن كنت بريميوم |
| لو محتوى مالي/منظم، أرفق إفصاح ثابت | لا تذكر عوائد/وعود بدون صياغة قانونية وإفصاح |

ملاحظات ختامية لتطبيق الدليل على Astroshot:
- حافظ على بساطة السؤال الافتتاحي + لقطة قبل/بعد تعكس الجودة.
- أعطِ التقنيات اسمها الإنجليزي بإيجاز، واشرح الأثر باللهجة: "لقطة تصيد العين، تخدم البيع".
- التزم بحرفنة الوقت: "نسلم أول نسخة خلال…"، "نلتزم بجدول…".
- استعمل مفردات الاجتماع: "يمعة ستوديو، فريق الديرة" لشعور القرب، بدون إسقاط الاحتراف.
